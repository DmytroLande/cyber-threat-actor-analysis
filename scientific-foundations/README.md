# Scientific Foundations

This directory contains previously published research that forms the scientific and methodological foundation of the project.

The selected publications address individual components that were subsequently integrated into the proposed methodology.

## Main Research Areas

The publications are grouped around the following areas:

- structured natural-language programming and AgentFlow;
- frameworks for constructing large agent prompts;
- adaptive virtual expert swarms;
- Retrieval-Augmented Generation for dynamic information collections;
- semantic networking and semantic knowledge representation;
- entity and assertion canonicalization;
- graph-based analytical models;
- explainable decision support and forecasting;
- OSINT and Cyber Threat Intelligence;
- cyber threat actor analysis and attribution.

Only officially published or otherwise publicly available works are included in this directory.
