# Experimental OSINT Datasets

This directory contains multilingual dynamic OSINT collections used as RAG contexts for experimental validation of the methodology.

## Dataset Groups

The experimental materials include:

- two English-language weekly OSINT collections;
- two Ukrainian-language weekly OSINT collections;
- document texts and available metadata;
- source references;
- publication dates;
- linguistic and thematic attributes required for retrieval and verification.

## Purpose

The datasets support:

- retrieval of relevant information fragments;
- multilingual entity identification;
- alias and descriptive-name resolution;
- extraction of attribution statements;
- source-origin analysis;
- evidence deduplication;
- temporal comparison of analytical results;
- construction and updating of semantic graphs.

## Data Availability

Before public release, all collections will be reviewed for copyright restrictions, personal data, confidential information, and source-specific redistribution limitations.
